# Intel Sustainability Summit: Event Check-in App

A React-based event check-in application for the Intel Sustainability Summit.

## Features

- **Attendee Check-In**: Check in event attendees with their name and selected sustainability team.
- **Goal & Attendance Tracking**: Live attendance counter against the 50-person summit capacity with animated progress bar indicator.
- **Team Breakdown**: Real-time attendance counters categorized by team:
  - 🌊 Team Water Wise
  - 🌿 Team Net Zero
  - ⚡ Team Renewables
- **Personalized Feedback**: Instant feedback greeting welcoming the attendee to their team.
- **Persistence**: Check-in data persists across page refreshes via `localStorage`, with an optional reset feature.
- **Brand Identity**: Intel corporate identity, typography, and styling with sustainability themes.

## Tech Stack

- React 19
- TypeScript
- Vite
